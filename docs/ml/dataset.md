# Data Sheet

## Общая информация

**Название датасета:** smoking, `richie-lab/smoking-tasfx`, версия 2.

**Источник:** [Richie Lab на Roboflow Universe](https://universe.roboflow.com/richie-lab/smoking-tasfx). Версия 2 указана в карточке выбранной модели на Hugging Face.

**Назначение:** обучение и оценка обнаружения объектов, связанных с курением; в выбранной модели используется класс `cigarette`.

**Лицензия:** на странице проекта датасета указана CC BY 4.0.

## Состав данных

**Объём:** согласно карточке модели, 12 046 изображений для обучения, 318 для валидации и 122 для тестирования; всего 12 486. Эти числа относятся к данным, заявленным автором модели для версии 2.

**Тип данных:** изображения с разметкой объектов ограничивающими рамками.

**Основные поля / признаки:** изображение, категория объекта и координаты рамки. Точные имена полей экспорта версии 2: **Не указано** в доступных источниках.

## Получение данных

Датасет опубликован Richie Lab в Roboflow Universe. Первоначальные источники изображений, условия съёмки и порядок отбора: **Не указано** в доступных источниках.

## Предобработка

В карточке модели указан размер изображения при обучении — 640 пикселей. Конкретные операции подготовки датасета и аугментации там не приведены: **Не указано**. Страница версии 2 при проверке была недоступна, поэтому её параметры предобработки не подтверждены.

## Ограничения

Доступной информации недостаточно для оценки разнообразия условий съёмки и качества разметки. На общей странице Roboflow представлены несколько версий и категорий; порядок выделения класса `cigarette` для выбранной модели не описан. Характеристики других версий нельзя автоматически переносить на версию 2.

## Использование в проекте

По сведениям автора, этот датасет использован для выбранной [модели](model-card.md). Для ACMS Censor его можно рассматривать как источник тестовых изображений для проверки обнаружения сигарет; соответствие пользовательским материалам проекта нужно оценить отдельно. В этой работе датасет не загружался, обучение и оценка модели не выполнялись.
