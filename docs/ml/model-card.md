# Model Card

## Общая информация

**Название модели:** Beehzod/best_smoke_cigarette-detection, детектор на базе Ultralytics YOLO11m.

**Источник:** [Hugging Face Hub](https://huggingface.co/Beehzod/best_smoke_cigarette-detection).

**Автор / организация:** Beehzod — автор публикации на Hugging Face.

**Задача модели:** обнаружение сигарет на изображениях, класс `cigarette`.

**Язык:** не применимо к входным данным: модель обрабатывает изображения; название класса — на английском.

**Данные для обучения:** smoking, `richie-lab/smoking-tasfx`, версия 2; подробнее в [Data Sheet](dataset.md).

**Лицензия:** в карточке модели указана MIT.

## Использование в проекте

В Censor уже предусмотрен `cigarette_detector`, а `process_image` пикселизирует найденные области выбранных категорий. Выбранная модель рассматривается как кандидат для этого детектора; использование именно её весов в существующем проекте не подтверждено.

В [учебном API](../api/index.md) операция `POST /censorings` передаёт изображение и категорию `cigarette` на обработку. В соответствии с [диаграммой последовательности](../project/diagrams.md) модель возвращает обнаруженные объекты, а приложение скрывает их области и сохраняет выходной файл.

## Входные данные

Изображение или отдельный кадр видео. При обучении, согласно карточке модели, использовался параметр размера изображения `imgsz = 640`.

## Выходные данные

Список обнаружений: категория `cigarette`, координаты ограничивающей рамки и оценка уверенности. Обработанное изображение создаёт приложение, а не сама модель.

## Метрики качества

Авторы приводят результаты на валидационной выборке: Precision — **0,8199**, Recall — **0,7650**, mAP@50 — **0,7898**, mAP@50–95 — **0,4617**. Это опубликованные показатели выбранной модели, а не результаты проверки на материалах ACMS Censor.

## Ограничения

1. По карточке модели поддерживается только класс `cigarette`; другие категории цензуры ACMS Censor этой моделью не покрываются.
2. **Потенциальное ограничение для нашего проекта:** мелкие, размытые или частично закрытые сигареты могут пропускаться; такие изображения нужно проверить отдельно.
3. **Потенциальное ограничение для нашего проекта:** качество на материалах ACMS Censor может отличаться от опубликованных метрик из-за других условий съёмки.

Подробные ограничения по условиям съёмки: **Не указано авторами модели.**

## Не рекомендуется использовать

Не рекомендуется полагаться на модель как на единственную проверку перед публикацией. Обнаружение похожего на сигарету объекта не следует использовать как доказательство того, что конкретный человек курит.
