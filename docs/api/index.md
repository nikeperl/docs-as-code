# API

API ACMS Censor предоставляет доступ к автоматической цензуре изображений — основному сценарию из практикума 2. Для практической работы описан контракт API; адрес сервера условный.

## Основные операции

- `POST /censorings` — обработать изображение и сохранить результат;
- `GET /censorings/{id}` — получить результат обработки по идентификатору;
- `GET /categories` — получить доступные категории объектов.

## Спецификация

Полное описание запросов, ответов и ошибок находится в файле [openapi.yaml](openapi.yaml).

Для просмотра загрузите файл в [Swagger Editor](https://editor.swagger.io/) через **File → Import file**. Отправлять запросы на условный сервер не требуется.
